# NewGameCode
All the games that I make are here. Check them out.

How To Play :
1. TIC-TAC-TOE :
    -> Play either versus self or computer by running the classes TTTPvP and TTTPvC respectively.
    -> Select difficulty against computer. Easy - 1, Medium - 2, Hard - 3
    -> Enter the coordinates either as <Row Column> or Row then Column
    -> Enter <0 0> to quit the game
